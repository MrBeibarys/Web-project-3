Кароче, че надо сделать чтобы оно работало на ура.

1. Запусти бэкенд.
    Ну кароче должно быть изи.
    1. зайди в папку бэкенд.
    2. через pip install скачай deepface fastapi pydantic numpy opencv-python
    3. запусти через uvicorn main:app --reload --port 3429 --host 0.0.0.0
    4. смотри в логи
    5. Там по ходу нужно будет скачать еще 2 библиотеки помойму. Помойму первый ts-keras а второй torch или touch. ну кароче скачаешь есть же
    6. Там когда зайдешь уже на сайт включишь вебку, там сново будут скачивиться штуки разные, так что держись, если что деньги дам на баланс.

2. запусти фронтэнд
    Ну тут мега изи
    1. зайди в ./frontend
    2. напиши npm i что скачать все зависимости
    3. npm run dev чтобы запустить сайт

3. запусти ngrok.
    ну тут сматрти
    1. зайди в папку ngrok.yml то есть самая верхняя
    2. введи ngrok start --all --config ngrok.yml
    3. ждемс
